## 一、图标没占满：根因是没用 adaptive icon

Android 8+ 的启动器会把**旧式方图**（`mipmap-*/ic_launcher.png`）塞进自己画的白色安全区里再按遮罩裁切，
所以即使 PNG 本身是满铺正方形，桌面上看到的一定是「白底 + 缩小后的图案」。

修法 —— 补 adaptive icon（`mipmap-anydpi-v26/ic_launcher.xml`）：

```xml
<adaptive-icon>
  <background android:drawable="@color/ic_launcher_bg"/>   <!-- 绿底满铺被遮罩，无边 -->
  <foreground android:drawable="@mipmap/ic_launcher_foreground"/>
</adaptive-icon>
```

- `values/colors.xml`：`ic_launcher_bg = #FFA0CFAF`（取自 `icon_1_192.png` 角点底色）
- `mipmap-{ldpi…xxxhdpi}/ic_launcher_foreground.png`：把 S 标从底图上抠出来（按底色做软边），
  等比缩到画布 **56%** 居中 → 落在 108dp 画布的 66dp 安全区圆内，任何遮罩都不切边
- `mipmap-{ldpi…xxxhdpi}/ic_launcher.png`：同时重出**满铺方图**（绿底 + S 标 74%），给旧启动器/通知兜底
- `ic_launcher_alt.png`：icon_2 浅蓝底同尺寸备着，以后换底色只改 `colors.xml` 一个值

生成脚本：`tools/make_icon.py`（可重跑，源图路径写在 `SRC`）。

## 二、隐藏「获取帧」：吊舱帧入口挪进设置页

- 工具栏删除「📷 获取帧」，`#grabStereo` 升为唯一主按钮「👁 获取双目」。
- `frameSrc` 默认值 `'pod'` → `'stereo'`：进 App 就是双目口径，检测/标注/校准都作用在双目帧上。
- 「获取帧」按钮**保留在 DOM 里但 `display:none`**（`recompute`/事件绑定仍引用它，删节点会报错），
  设置页新增「抓取吊舱帧（仅看图/手动标注，不出 mm、不参与纠偏）」，走同一个 `fetchFrame()`。
- 标题栏 `吊舱↔双目 对比验证` → **手动校准 / Manual Calibration**（与桌面名、`<title>` 一致）。

## 三、结果区重排

原来一行 4 格（吊舱 dx/dy 隐藏后剩 2 格小字）+ 一句长文案折行。

现在右侧面板自上而下：

1. `纠偏量` 标题 + `mm` 单位胶囊
2. 两张并排卡片：**水平 dx** / **垂直 dy**，字号 21px 等宽数字（`tabular-nums`，负号不跳动），单位小字
3. 合位移行：`合位移 19.0 mm` + 右侧圆角 chip `参与 4/4`（中性色，不再是抢眼的蓝）
4. `帧源 双目 1536×1280`、`板心 (762.6, 566.1) px` 两行左标签右数值
5. 分隔线 + `选中圆微调`：方向键（40px）与 `缩小`/`放大` **并排**（原来上下两行，白占 40px）
6. 图内 1~4 编号改 12px + 黑描边，反光亮背景下也读得清
